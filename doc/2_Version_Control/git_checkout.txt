git commit
- saves staged changes as a commit
-m "message" = adds a commit message.

git branch
- lists branches

git checkout
switches to a branch
-b <name> = creates a new branch and switches to it.

git pull
- gets changes from a remote and merges them into your current branch

git push
- uploads commits to a remote repository
-u <remote> <branch>

git merge
- merges another branch into your current branch

git rebase
- moves your commits onto another branch.

git fetch
- downloads changes from a remote without merging them

git add
- stages a file/change for the next commit

git status
- shows the current state of the repo and its files

git log
- shows the commit history
- newest commits are shown first.

git diff
- shows changes that aren't staged yet
